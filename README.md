# ZingZing ZangZang — website thương hiệu

Frontend Next.js App Router + TypeScript + Tailwind CSS 4, tiếng Việt, responsive.

## Chạy trên máy

Yêu cầu Node.js 20.9+ (khuyến nghị Node.js 22 LTS).

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Production

```bash
npm run build
npm run start
```

Dùng Nginx reverse proxy tới localhost:3000 và Cloudflare Tunnel cho domain.

## Lưu ý trước khi công bố

- Mascot hiện là minh họa bằng CSS, không phải tài sản 3D chính thức. Có thể thay bằng ảnh PNG/WebP mascot đã được phê duyệt.
- Các trạng thái sản phẩm/game là nội dung minh họa; cần cập nhật theo tình trạng phát hành thực tế.
- Email hello@zingzingzangzang.com chỉ là địa chỉ đề xuất: thay bằng địa chỉ đang sử dụng.
- Trang /privacy-policy là placeholder, **phải thay bằng chính sách thực tế** trước khi công bố.
- Chưa tích hợp CMS, biểu mẫu, tracking, Google Play link hoặc API.
